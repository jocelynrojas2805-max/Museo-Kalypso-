# Museo-Kalypso-
Bienvenido a Museo Kalypso puedes hacer tu reservación 
El proyecto consiste en la creación e implementación de una plataforma web interactiva diseñada para optimizar la gestión de boletos del Museo Kalypso. El sistema busca transformar la experiencia del visitante al digitalizar el proceso de compra y, al mismo tiempo, hacer más eficiente la operación interna del personal del museo.
